Hva nettstedet gjør og hvem det er laget for: 
Hundekatalogen er en nettside der du kan utforske ulike hunderaser. Du kan søke opp en bestemt rase eller filtrere etter dine preferanser. Tanken bak nettsiden er at alle som ønsker å anskaffe seg en hund kan få innblikk i hvordan de ulike rasene vil fungere i egen livssituasjon. 

Det er en side med oversikt over alle hunderaser i APIet. Disse er paginert med 30 på hver side. Om du klikker deg inn på en av hunderasene kommer du til en dedikert side til den rasen. Det er også lagt opp både søk og filtrering. Søkefunksjonen fungerer opp mot rasenavn (riktignok på engelsk), og filtreringen fører deg til en ny side hvor du får opp kortene til de aktuelle hundene. Begge funksjonene gir melding til brukeren om ikke det er noen treff. 

Hvordan prosjektet installeres og startes: 
- Prosjektet krever node.js 
- git clone https://github.com/Annine-Hausberg/DogBreedSearch_arbeidskrav2_h26.git
- npm install
- npm run dev

API:
Hundene og tilhørende detaljer er hentet fra DogAPI: https://dogapi.dog/api/v2/breeds 
API`et er gratis og uten API-nøkkel.
